# Capability evidence replies: OpenCode 2.0.30, 2026-11-04

This file is the per-sample companion to the
[evidence file](2026-11-04-opencode-2.0.30.md). It lists, for every one of the
24 models attempted, the step-1 rendered configuration facts, the text-control
result, and the reply recorded for every sample in every configuration,
including the explicit `["text"]` negative control.

How to read it:

- Each reply is shown as a JSON string, so newlines and quotes are exact and
  nothing is rendered as Markdown. Replies are the verbatim text stored by the
  run, capped at 500 characters by the script as recorded. Six replies are exactly 500 characters long and so may be truncated.
- Each line reads `<configuration> #<sample> <classification> expected <token>`
  followed by the reply.
- `unset` means `modalities.input` was not set; `text-image` is explicit
  `["text","image"]`; `text-only` is explicit `["text"]` (the negative control).
- Step-1 facts are `modalities.input` and `reasoning` as OpenCode rendered them
  for the model before any override. `absent` means the key was not present.
- The machine-readable source of every line is
  [the results JSON](2026-11-04-opencode-2.0.30-results.json) (also available as
  [TSV](2026-11-04-opencode-2.0.30-results.tsv)).
- This file is derived from that JSON by a mechanical transform. It adds no
  interpretation.
