# Example Input: Benefits Information Page

## Purpose

Create a static HTML page explaining federal benefits eligibility for the public.

## Target Audience

- General public
- People unfamiliar with government services
- Screen reader users

## Required Content

### Page Title
"Am I Eligible for Benefits?"

### Sections Needed

1. **Introduction** — Brief explanation of what benefits are available
2. **Eligibility Criteria** — Bulleted list of requirements
3. **How to Apply** — 3-step process
4. **Get Help** — Contact information

### Call to Action
"Check Your Eligibility" button linking to `/eligibility-check`

## USWDS Components to Use

- Basic header with service name
- Alert box for important notice
- Process list for steps
- Button for primary CTA
- Slim footer

## Accessibility Requirements

- Must work with keyboard navigation
- Must have logical heading hierarchy
- Skip link required
- All content must be accessible to screen readers

## Notes

- Use placeholder content where specific copy isn't provided
- Include HTML comments for human review points
- Do not include agency-specific branding
