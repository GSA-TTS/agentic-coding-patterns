# Support

The Agentic Coding Patterns repository is a hub of reusable patterns, prompts,
skills, and workflows for agentic coding, maintained by and for the federal
agentic-coding community.

## Documentation

- [README](README.md) — overview
- [docs/getting-started.md](docs/getting-started.md) — start here
- [docs/](docs/) — full documentation

## Questions or help

Open a [GitHub issue](https://github.com/GSA-TTS/agentic-coding-patterns/issues)
(or a Discussion, if enabled). Others benefit from the answer too.

## Bugs and feature requests

Open a [GitHub issue](https://github.com/GSA-TTS/agentic-coding-patterns/issues)
with steps to reproduce (for bugs) or a clear description of the request.
